# RaceDay

## South African Road Running, Walking and Cycling Event Management System

RaceDay is a full-stack web-based event management platform designed for the South African road running, walking and cycling community.

The system is designed to address common problems experienced by event organisers, including paper-based registration, spreadsheet-based administration and disconnected communication channels.

RaceDay provides a central platform where Organisers can manage sporting events, categories, participant enrolments and race results, while Participants can browse events, register for events and track their personal race history.

The project is being developed progressively across three Portfolio of Evidence parts.


# Project Overview

RaceDay is designed around two primary user roles:

### Organiser

Organisers are responsible for managing sporting events and their associated information.

An Organiser can:

- Create events
- Edit events
- Delete events
- Manage event categories
- View participant enrolments
- Capture participant results
- Update race results
- Manage event route information
- Manage event weather information
- Upload event banner images

# Participant

Participants use RaceDay to discover events and manage their participation.

A Participant can:

- Create an account
- Log in
- View and update their profile
- Upload a profile picture
- Browse upcoming events
- View event information
- View available categories
- Enrol in events
- Select an event category
- View their enrolments
- View their personal race results
- Track their race history

Role-based access control ensures that users can only access functionality appropriate to their role.
