# Part 3 — 20 meaningful commit checkpoints

**These are suggested commit units, not commits that have already been made.** The delivered ZIP does not contain a fabricated Git history. When importing the ZIP, review changes and make feature-based commits only where the staging/content accurately reflects the change. Preserve your existing Part 2 history, and don't split already committed files artificially.

1. Add ASP.NET Core MVC project and solution integration
2. Configure MVC startup, HTTP client and appsettings
3. Add shared API response and DTO models
4. Add server-side session management and role access filter
5. Implement MVC login against Part 2 API
6. Implement MVC registration and logout
7. Implement role-specific navigation and shared layout
8. Add event discovery homepage and filtering
9. Add event detail and category selection interface
10. Implement participant enrolment form
11. Add participant My Events and status views
12. Add participant My Results and profile management
13. Add organiser dashboard event and enrolment statistics
14. Implement organiser event CRUD and banner workflow
15. Implement organiser category management
16. Implement organiser participant and results pages
17. Add Azure Blob image service in API
18. Add API image endpoints and private image display integration
19. Add MVC Dockerfile and documented run command
20. Add Part 3 CI workflow, final README and evidence checklist

For every checkpoint, run an appropriate build/smoke test before committing. If your code is already committed together, new meaningful fixes/tests/documentation are safer than pretending it was developed in 20 separate historical steps.
